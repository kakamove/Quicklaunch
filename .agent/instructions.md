# Agent & OpenSpec Instructions

## OpenSpec 语言规范 (Language Policy)

在为此项目生成或更新 OpenSpec 变更文档（包含 `proposal.md`, `design.md`, `tasks.md`, `specs/**/*.spec.md` 等）时，必须遵守以下语言规范：

1. **说明与表达使用中文**：所有的意图背景、问题分析、设计方案推导、逻辑说明、任务清单及 Scenario 描述统一使用 **简体中文** 编写。
2. **保留 OpenSpec 关键字**：OpenSpec 的 Schema 结构标题与固定断言关键字（如 `## Intent`, `## Capabilities`, `Scenario:`, `GIVEN`, `WHEN`, `THEN`, `SHALL`, `MUST` 等）保持英文。
3. **保留技术术语**：专有名词、技术术语、CLI 命令、文件名、代码符号、库名（例如 `tmux`, `Ghostty`, `zsh`, `config.yaml`, `fzf`, `xcworkspace` 等）保持英文原文。
